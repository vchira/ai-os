# Support & Contact

## Getting help

### Self-diagnostics

Before seeking help, run the built-in self-test:

```
/selftest
```

This checks all system components and reports what is working and what is not. Include the results when reporting issues.

### Documentation

This user guide covers most common questions and issues:

- [Common Issues](troubleshooting/common.md) -- solutions to frequently encountered problems
- [Audio Problems](troubleshooting/audio.md) -- microphone and speaker troubleshooting
- [Network & Connectivity](troubleshooting/network.md) -- internet and channel connectivity
- [FAQ](faq.md) -- frequently asked questions

### Ask the AI

The AI assistant itself can help with many issues:

- "Something is wrong with my audio"
- "The web channel is not working"
- "How do I change my API key?"

The AI has access to system tools and can diagnose problems in real time.

## Reporting bugs

If you encounter a bug, please report it on the GitHub issue tracker:

> **[github.com/swit-work/ai-os/issues](https://github.com/swit-work/ai-os/issues)**

When reporting a bug, include:

1. **AiOS version** -- run `/info` to find it
2. **Self-test results** -- run `/selftest` and include the output
3. **Steps to reproduce** -- what you did, in order
4. **Expected behavior** -- what you expected to happen
5. **Actual behavior** -- what actually happened
6. **Hardware** -- CPU, RAM, and any relevant peripherals (audio devices, etc.)
