About AiOS

An AI-native Linux distribution where the AI is the interface

The Vision

Most operating systems treat AI as an application — a chatbot window sitting alongside file managers and terminals. AiOS takes the opposite approach: the AI is the primary interface between humans and the machine.

You speak or type what you want. The AI understands your intent, decides what needs to happen, and uses tools to execute it. Files, processes, network, hardware — everything is accessible through conversation. The traditional desktop chrome fades into the background; the AI brings forward exactly what you need, when you need it.

AiOS is not a voice assistant bolted onto Linux. It is a distribution designed from the ground up so that every component — the compositor, the audio stack, the security model, the tool system — serves the AI-first interaction model.

How It Works

AiOS is built on a proven foundation with modern components chosen for reliability and minimal resource usage:

  • Base: Debian Bookworm (12) — broad hardware support, stable package ecosystem
  • Display: Wayland via labwc — a lightweight wlroots-based compositor built from source
  • Application: Rust with GTK4 and libadwaita — a single native binary, no runtime dependencies
  • Voice STT: whisper.cpp — local speech-to-text inference, multiple model sizes for different hardware
  • Voice TTS: Piper (primary) and espeak-ng (fallback) — all voice processing stays on-device
  • LLM Providers: Claude and OpenAI APIs — switchable at runtime through a provider trait
  • Audio: PipeWire — modern Linux audio with low latency
  • Networking: Avahi mDNS — the web interface is reachable as http://aios.local

The Rust application is organized as a workspace of focused crates: core types and configuration, LLM provider management, tool definitions and sandboxing, voice engine backends, GTK desktop UI, web channel server, and Signal messenger integration.
