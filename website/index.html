Quick Start

1

Download

Grab the latest ISO image from the Releases page or from GitHub Releases.

2

Boot in a VM

Launch AiOS in QEMU with audio and clipboard support: 

qemu-system-x86_64 \
  -cdrom aios-*.iso \
  -m 4G \
  -smp 2 \
  -enable-kvm \
  -device virtio-vga-gl \
  -display sdl,gl=on \
  -device intel-hda \
  -device hda-duplex \
  -nic user,model=virtio-net-pci
3

Or Write to USB

For bare-metal installation, write the ISO to a USB drive: 

sudo dd if=aios-*.iso of=/dev/sdX bs=4M status=progress oflag=sync

Replace /dev/sdX with your USB device. All data on the drive will be erased.
